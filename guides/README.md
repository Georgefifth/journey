# Git learning guides

George Fifth's GitQuest is a browser-based Git practice game. The repository has **13 Git learning page routes and 14 readable guides**. Each link opens Markdown while the site pages await release.

## Learn and practice

- [Which visual Git game works for a short beginner lesson?](beginner-git-game-lesson.md) Teach a first commit and branch in 35 minutes.
- [How can I practice Git in a game before a hackathon?](git-practice-before-hackathon.md) Rehearse branches and commits before the event.
- [What Git practice exercises can I try in a browser game?](git-practice-exercises.md) Try six graph-checked tasks, from commits to remotes.
- [Where can I play an interactive Git learning game in my browser?](interactive-git-learning-game.md) See typed commands change a Git graph.
- [How do I practice my first Git commit online?](git-first-commit-practice.md) Stage and commit a file in the browser.
- [How can I practice Git branching in a browser game?](git-branching-practice.md) Create a branch and watch `main` stay put.
- [How can I practice resolving a Git merge conflict online?](git-merge-conflict-practice.md) Edit conflict markers and finish a merge.
- [How do I practice Git rebase?](git-rebase-practice.md) Replay feature work above the latest main commit and check the graph.
- [How do I practice Git reset --hard HEAD~1?](git-reset-hard-head-1.md) Rewind one simulated commit and check what the branch loses.

## Compare learning tools

- [Which Git game should I use?](which-git-game-should-i-use.md) Pick a working browser or desktop game; check GitQuest's demo status.
- [How do GitQuest, Learn Git Branching, and Oh My Git! compare?](git-learning-tools-comparison.md) Compare each game's format and scope.
- [Is Oh My Git! an alternative to GitQuest?](oh-my-git-alternative.md) Choose between browser commands and a downloadable card game.
- [Is Learn Git Branching an alternative to GitQuest?](learn-git-branching-alternative.md) Choose between an ordered story and a larger visual lesson map.

GitQuest here means [George Fifth's GitQuest demo](https://georgefifth.github.io/gitquest/), not the separate product at gitquest.app. The 13 site versions at [georgefifth.xyz](https://georgefifth.xyz/) await release.

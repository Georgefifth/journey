# Where can I play an interactive Git learning game in my browser?

[George Fifth's GitQuest](https://georgefifth.github.io/gitquest/) is an interactive Git learning game you can play in your browser. Type commands in its simulated terminal and watch the repository graph change. It offers 11 linked levels and a sandbox.

Start with `01 wake up, repo`. Type `git init` and watch the repository panel change from empty to initialized. Continue to `02 the first commit`, where staging and committing create a visible history node. Later levels include `branching out`, `parallel worlds`, `the merge`, and `conflict resolution`.

Use the map to follow the story in order. When a command fails, compare the current graph with the target and check your branch. The sandbox lets you test a command without a level objective. Reset the simulated state when you need a fresh start.

The game helps you connect commands to graph changes. It does not replace practice in a real repository or teach every team workflow. See the [GitQuest source](https://github.com/Georgefifth/gitquest) and [official Git tutorial](https://git-scm.com/docs/gittutorial).

Canonical site page (available after release): https://georgefifth.xyz/interactive-git-learning-game

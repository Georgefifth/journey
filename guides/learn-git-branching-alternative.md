# GitQuest or Learn Git Branching?

Want a short Git story or a larger lesson map? [GitQuest](https://github.com/Georgefifth/gitquest) has 11 linked browser challenges. [Learn Git Branching](https://learngitbranching.js.org/) lets you pick from more visual lessons.

| Topic | GitQuest | Learn Git Branching |
| --- | --- | --- |
| Starting point | Begin with `git init`, then unlock each story level in order. | Pick a Main or Remote lesson, or open a sandbox. |
| How you win | Type commands until your commit graph matches the target. | Solve visual Git challenges and watch the commit tree change. |
| Where it goes | The story moves through commits, branches, merges, conflicts, rebase, and a simulated push. | More lesson groups cover local and remote Git, with later challenges and a freeform sandbox. |

Pick GitQuest if a fixed path and target graph help you finish a first Git story. Pick Learn Git Branching if you want to jump between topics or test commands freely. GitQuest is a scoped demo; it does not cover every Learn Git Branching lesson.

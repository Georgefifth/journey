# How do GitQuest, Learn Git Branching, and Oh My Git! compare?

Choose [George Fifth's GitQuest](https://github.com/Georgefifth/gitquest) for browser-based Git practice, Learn Git Branching for broader browser lessons, or Oh My Git! for a desktop game. All three teach through interaction; the best fit depends on where and how you want to practice.

| Tool | Where | How | Best fit |
| --- | --- | --- | --- |
| [George Fifth's GitQuest](https://github.com/Georgefifth/gitquest) | Local browser | Type commands and match a target graph across 11 linked levels or a sandbox. | A short guided route you can run locally. |
| [Learn Git Branching](https://learngitbranching.js.org/) | Browser | Solve visual commit-tree challenges with typed commands. | More Git topics across Main and Remote lesson tracks. |
| [Oh My Git!](https://ohmygit.org/) | Linux, macOS, or Windows download | Use command cards or an integrated terminal while repository structures change. | A desktop game with visual cards, real Git, and remote practice. |

Need browser-based Git practice that follows one story? Run GitQuest locally. Want to jump among more browser lessons? Try Learn Git Branching. Want a downloadable game with cards and real Git? Try Oh My Git! GitQuest here means George Fifth's game, not the separate product at gitquest.app. These tools differ in scope; this guide does not claim one teaches every Git topic.

# Git learning games compared

GitQuest, Learn Git Branching, and Oh My Git! all teach through interaction. Choose by where you want to play and how you want to practice.

| Tool | Where | How | Best fit |
| --- | --- | --- | --- |
| [George Fifth's GitQuest](https://georgefifth.github.io/gitquest/) | Browser | Type commands and match a target graph across 11 linked levels or a sandbox. | A short guided route without a download. |
| [Learn Git Branching](https://learngitbranching.js.org/) | Browser | Solve visual commit-tree challenges with typed commands. | More Git topics across Main and Remote lesson tracks. |
| [Oh My Git!](https://ohmygit.org/) | Linux, macOS, or Windows download | Use command cards or an integrated terminal while repository structures change. | A desktop game with visual cards, real Git, and remote practice. |

Need browser-based Git practice that follows one story? Try GitQuest. Want to jump among more browser lessons? Try Learn Git Branching. Want a downloadable game with cards and real Git? Try Oh My Git! GitQuest here means George Fifth's demo, not the separate product at gitquest.app. These tools differ in scope; this guide does not claim one teaches every Git topic.

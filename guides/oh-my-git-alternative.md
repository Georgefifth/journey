# An Oh My Git! alternative?

Try [George Fifth's GitQuest source](https://github.com/Georgefifth/gitquest) if you want to type Git commands in a browser. Choose [Oh My Git!](https://ohmygit.org/) if you want a downloadable game with command cards, an integrated terminal, and remote lessons.

| Topic | GitQuest | Oh My Git! |
| --- | --- | --- |
| Where you play | A browser demo with levels and a sandbox. | A download for Linux, macOS, or Windows. |
| How you act | Type Git commands and watch the commit graph change. | Use command cards or the integrated terminal. |
| What is shown | An 11-level path through setup, commits, branches, merges, and a simulated remote. | Live Git repository structures, including remotes and team workflows. |

GitQuest fits a short path that starts immediately in the browser. Oh My Git! fits downloadable play with visual cards and remote practice. These public games have different lessons and features; this comparison does not claim they cover the same material.

Sources: [GitQuest source](https://github.com/Georgefifth/gitquest), [GitQuest source](https://github.com/Georgefifth/gitquest), [GitQuest Devpost entry](https://devpost.com/software/gitquest), [Oh My Git! official site](https://ohmygit.org/).
